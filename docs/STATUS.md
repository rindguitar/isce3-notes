2026-09-16（4 本目）: **「複製」の意味と、2 次元に適用したときの壊れ方を実測した。**

- 発端: 「なぜ 1 次元の道に入ると複製され、その結果困るのか」という問い
- **複製の意味**: ジオコーディングは**面を貼る処理**。1 次元には距離軸が無いので
  **距離方向へ引き伸ばして面にする** = その時刻はスワス全体で同じ標高とみなす。
  1 本の値しか無い以上、**唯一できる解釈**（手抜きではない）
- 🔴 **2 次元に同じ式を当てると壊れることを実測**
  （`np.repeat(np.transpose([var_array]), samples, axis=1)`）

  | 入力 | 出力 | |
  |---|---|---|
  | `(80,)` | `(80, 240)` | ✅ 意図どおり |
  | `(80, 240)` | **`(240, 19200, 1)`** | ❌ 3 次元・要素数 240 倍 |

  直後の `length, width = new_var_array.shape` が **`ValueError` で落ちる**
- 意味の面でも、距離方向の変化を一定値で塗り潰すので **2 次元化の目的が消える**
- → **引き伸ばすかどうかはデータ自身の次元で決めるしかない**（周りの様子で決めてはいけない）
